# Architecture Decision Records

Mỗi quyết định kiến trúc quan trọng ghi một file `NNNN-tieu-de.md`, đánh số tăng dần. Không sửa ADR cũ; nếu đổi ý, viết ADR mới và đánh dấu ADR cũ là "Superseded".

Mẫu:

```md
# NNNN. Tiêu đề

- Trạng thái: Proposed | Accepted | Superseded by NNNN
- Ngày: YYYY-MM-DD

## Bối cảnh
## Quyết định
## Hệ quả
```
