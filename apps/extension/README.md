# apps/extension (`@cnweb/extension`)

Extension trình duyệt (Manifest V3, WXT hoặc Plasmo): hiển thị phụ đề song ngữ trên YouTube/Netflix/Bilibili, lưu từ về tài khoản.

**Giai đoạn 3 — chưa làm trong MVP.** Giữ thư mục để định hình kiến trúc (dùng chung `packages/ui`, `packages/shared`, gọi `apps/api`).

Nguyên tắc: chỉ đọc phụ đề có sẵn trên trang, không tải video, xin quyền tối thiểu.
